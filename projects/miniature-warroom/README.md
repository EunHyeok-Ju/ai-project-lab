# Miniature War Room

**여러 자동화 에이전트의 작업 흐름을 시각적으로 이해하기 위한 실험**  
**상태:** 콘셉트 및 로컬 프로토타입 단계 · 공개 배포 및 실제 연동 검증 전  
[← 프로젝트 목록](../../README.md)

## Idea

금융 데이터 수집, 품질 검증, 분석, 리포트 작성 등 여러 자동화 프로세스가 실행될 때 **무슨 작업이 진행 중이고 어디서 멈췄는지** 한눈에 확인할 수 있는 시각화 환경을 탐색하고 있습니다.

## Intended capabilities

- Collector / Processor / Analyst / Reporter 등 역할별 업무 진행 상황
- 실행 중·완료·실패·대기 작업과 작업 흐름 표현
- 마지막 성공 시각과 오류·실행 이력 탐색
- 실제 실행 기록을 읽기 전용으로 표시하는 운영 상태 화면

## Current boundary

사용자 작업 환경에서 UI 프로토타입 개발을 진행했지만, 이 페이지는 **완성된 운영 서비스나 실제 에이전트 자동 협업 구현을 의미하지 않습니다.** 공개 가능한 화면과 원격 운영 검증이 준비되면 실제 구현 범위를 추가할 계획입니다.
