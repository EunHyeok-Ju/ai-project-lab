## What I focus on

- **Domain-driven problem solving** — 문제의 업무적 의미와 예외 케이스부터 정의합니다.
- **AI-assisted engineering** — AI 코딩 도구를 활용하며 설계·검증·운영의 판단 근거를 기록합니다.
- **Data correctness** — 숫자의 출처와 기준 시점, 누락, 중복, 변경 이력을 중요하게 다룹니다.
- **Reliable automation** — API, 스케줄러, CI, 데이터베이스, 배포를 실제 사용 흐름으로 연결합니다.

## Public portfolio vs. private implementation

이 저장소는 **공개 Showcase**입니다. 실제 구현 저장소나 데이터베이스 덤프를 복제한 곳이 아닙니다. 각 프로젝트는 **운영 확인 / 구현·검증 / 개발 중 / 계획**을 구분해 기술합니다.

개인 금융정보, 인증정보, 게임 계정 식별자, 회사의 내부 자료 등은 게시하지 않습니다. 공개 스크린샷과 시연 영상은 내용을 검토한 뒤 추가할 예정이며, 현재 누구나 접속할 수 있는 데모는 제공하지 않습니다.
