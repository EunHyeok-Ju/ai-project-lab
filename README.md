### Why this repository?

이곳은 **공개 포트폴리오**이고, 원본 구현 코드는 별도의 **비공개 저장소**에서 관리합니다. 공개 웹사이트의 화면은 제품의 실제 화면을 그대로 복제한 것이 아니라, 프로젝트 컨셉을 설명하는 안전한 시각화입니다. 구현 여부, 실제 운영 여부, 개발 계획은 구분해 표시합니다.
